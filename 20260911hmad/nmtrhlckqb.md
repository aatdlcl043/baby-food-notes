# 孕34周羊水深度标准

孕34周羊水深度标准
　　孕34周的羊水指数的标准范围为5.0cm-18.0cm。羊水对胎儿具有天然的保护作用，保护胎儿免受外力冲击，同时也可以减少胎儿在母体内活动时对孕妇带来的不适感。随着孕周的增加，羊水量也会随之增加，正常妊娠羊水量的正常范围是500-2000ml，在孕34周之后，羊水内存在颗粒状回声或细短光带。以脐水平线和腹白线为标志可以将子宫直角分成四个象限，测量各象限最大羊水池的垂直径线，四者之和即为羊水指数。孕妇需要定期去医院进行检查，查看羊水量。

　　羊水指数(Amniotic Fluid Index 缩写:AFI)：以脐水平线和腹白线为标志将子宫直角分成四个象限，测量各象限最大羊水池的垂直径线，四者之和即为羊水指数。
