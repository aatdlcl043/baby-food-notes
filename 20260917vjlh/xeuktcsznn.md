**
孩子缺不缺？看这些信号
**
我国相关调查显示，每10个孩子中就有1个缺维生素A，2个处于临界值；1-7岁孩子约14%缺维生素D，年龄越大越容易缺。
**缺维生素A表现**

✓ 晚上眼睛看不清

✓ 眼睛干涩总揉眼

✓ 皮肤粗糙像砂纸

✓ 经常感冒好得慢

**缺维生素D表现**

✓ 后脑勺头发稀疏（枕秃）

✓ 睡觉翻来覆去常惊醒

✓ 囟门2岁还没闭合

✓ 出牙晚、走路迟

建议：出现以上这些情况，应该及时去医院查血，维生素A＜1.05μmol/L、维生素D＜50nmol/L即为缺乏，应当适当补充。

科学补充三招鲜
****晒太阳小技巧**

✓ 增加日照，要接触无玻璃遮挡的散射光（避开正午）

✓ 每天累计1-2小时

✓ 小婴儿避免直晒，记得戴帽子

**优先食补**

✓缺乏维生素A，可以吃蛋黄、猪肝、胡萝卜、南瓜、菠菜、芒果

✓缺乏维生素D，可以吃乳酪、蛋黄、肝脏、海鱼

**精准补充**

✓ 出生1周内，尽早开始补

✓  常规剂量：

 0-1岁：每天维生素A1500单位+维生素D400单位

 1-18岁：每天维生素A1500-2000单位+D400-800单位

✓ 特殊宝宝要加量：

**早产/双胞胎、低体重**：前3个月维生素A1500-2000单位+维生素D800单位，之后减量至维生素A1500单位+维生素D400单位

**常拉肚子、老感冒：**维生素A2000单位，维生素D800单位

**贫血、营养不良：**维生素A1500-2000单位+维生素D400-800单位

常见问题答疑
****Q****鱼油能代替维生素AD补充剂吗？**
鱼油提取自深海鱼脂肪，富含不饱和脂肪酸，不适合作为AD补充剂，现在专门的维生素AD补充剂配比更科学（3:1黄金比例）。
**维生素补多了会中毒吗？****Q**
按推荐量补充一般都是安全的，但要注意，别狂吃动物肝脏，每日摄入量不能超过半斤，别自己把补充剂加量，如维生素A超5-10万单位连吃6个月、维生素D超4000单位连吃几周可能中毒。
**Q****补充维生素，光靠吃饭和晒太阳行吗？**
不行。特别是喝配方奶的宝宝，要计算配方奶中已有的维生素量，不够的部分用补充剂补充。
