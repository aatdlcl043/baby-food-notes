# 【科普】敲黑板！中成药的四个使用“药”点要牢记

> 更新时间：2026-09-16 (UTC+8)

现在不少人喜欢用**中成药**，中成药本质还是属于中药，但想要取得较好的疗效，充分发挥中成药的治疗作用，就要求使用者必须严格按照中医的理论来使用。

今天，我们就邀请新疆维吾尔自治区妇幼保健院（自治区第八人民医院）专家来为大家科普**中成药的那些使用“药”点**。

**辨证用药**

中成药是在中医药理论指导下制成的，最基本原则就是辨证论治。不仅要依据中医理论，还需辅以西医诊断来综合辨认、分析疾病的证候，从而选用相应的中成药。

但仅依据西医诊断选用中成药，有发热就服用清热解毒类中成药，有咳嗽就用止咳化痰类中成药，并不能真正做到辨证施治，难以达到最佳疗效。此外，还应根据自身情况如体质强弱、病情轻重缓急及各种剂型的特点，选择适宜的剂型。如病情急重或昏迷，不能吞咽情况下可选用注射剂；酒剂、酊剂含有酒精，小儿、孕妇及酒精过敏者不宜使用；糖尿病患者慎用糖浆剂等。

**服用剂量**

中成药因其安全性高，不良反应少，容易令人产生多吃或少吃一次，多吃或少吃一点没什么影响的想法，对于这个问题应具体情况具体分析。

对于高风险中成药，如含毒性中药材成分（川乌、草乌、马钱子、水蛭、细辛等），此类中成药药性偏高，对机体的状态和身体的选择性强，使用时容易出现不良反应，所以使用此类中成药时要严格按照说明书或医嘱用药。通常从小剂量开始逐渐加量，而需长期用药的，必须防范药物可能出现的积蓄性中毒，可在医嘱下逐渐减量，或采取间歇给药等方式。

**联合用药**

当病情复杂，一种中成药不能满足所有证候时，我们可以联合应用多种中成药，但在使用过程中应遵循药效互补原则及增效减毒原则。

药效相同或含有同一成分的中成药原则上不宜叠加使用，应根据中西医诊断和各自的用药原则选药，充分考虑药物之间的相互作用，尽可能减少联用药物的种数和剂量。

必须同一途径用药时，应将中西药分开使用，谨慎考虑不同药物的使用间隔时间以及药物互相作用，严禁混合配伍。

**特殊人群用药原则**

**◆儿童——**儿童选用中成药时，使用中成药的种类不宜多，尽量采取口服或外用途径给药，谨慎使用中药注射剂。用药剂量要兼顾安全性和有效性，首选儿童专用中成药。一般情况下儿童专用中成药说明书都列有与儿童年龄或体重相应的用药剂量，应根据推荐剂量选择相应药量。

**◆孕妇——**妊娠期妇女必须用药时，应选择对胎儿无损害的中成药。尽量采取口服途径给药，慎用使用中药注射液；根据中成药治疗效果，尽量缩短妊娠期妇女用药疗程，及时减量或停药。

**◆老年人——**由于老年人身体机能逐渐衰退，病情往往复杂多变，虚实夹杂，并伴随多种疾病。所以用药不宜过偏过猛，以免损伤正气。有使用剂量范围的中成药，老年人使用剂量应取偏小值。长期与降血压降血糖等慢性病西药联用时，应定期监测指标。
**◆特殊人群——**过敏体质人群与肝肾功能异常的人群应在医师的指导下慎用部分中成药。避免无适应症用药、大剂量用药、长时间用药。肝肾功能异常者服药期间应定期检查尿液、转氨酶、肌酐等肝肾功能指标。
